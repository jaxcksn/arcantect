# Claude.md

Arcantect is a browser based puzzle game that teaches cloud architecture and
systems design! You recieve a prompt, and you must assemble a cloud architecture diagram.

Afterwards, the crystal ball with tell you your score!

---

The frontend uses a node based interface, the user recieves a prompt for a cloud based system in textual format and the scoring system will calculate the result. The prompt has a hidden rubric that is used.
